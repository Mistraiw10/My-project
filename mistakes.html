Полоть сорняки

Ошибки по играм

Как это работает

  • Каждая ошибка в любой игре вырастает в саду сорняком.
  • «Полоть» - это задания только из твоих ошибок, до 8 за раз, из всех игр сразу. Спрашивается то, в чём ты ошибся: реагенты, продукт, название или структура.
  • Звёзд здесь нет. Вместо них счёт: 1 из 2, 2 из 2. Ошибёшься - счёт начнётся сначала.
  • На «2 из 2» получаешь лопату. Нажми на подсвеченный сорняк - он выкопается, и проплешина снова зарастёт цветами.
  • Счёт общий с обычными играми: верные ответы там тоже могут дать лопату.
  • Выкапывать сорняки можно всем. Полоть - то есть решать задания только из своих ошибок - можно с премиумом.

Доступно с премиумом

С премиумом можно полоть: решать задания только из своих ошибок, пока сад снова не зацветёт.

Без премиума лопату тоже можно заработать - верными ответами в обычных играх.

А ещё с премиумом бесконечные жизни во всех играх.
